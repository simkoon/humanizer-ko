This is an unofficial adaptation, not an official translation or an endorsement by the upstream author. The editing workflow and pattern families are adapted from upstream. Korean examples, Korean grammar guidance, genre safeguards, documentation and test fixtures were written for this project with AI assistance. The English examples were not translated wholesale. Version 0.1.0 is this project's version, not the upstream version.

Notable differences:

- Replaces English-specific orthography rules with Korean grammar and register guidance.
- Uses contextual editing rather than unconditional bans on contrast, dashes or a word list.
- Preserves uncertainty, agency, scope, code and quotations.
- Does not add personal experiences or reactions to imitate a human author.
- Returns the final rewrite by default.

The upstream project cites Wikipedia's “Signs of AI writing” as background. No Wikipedia article text is reproduced here. That article is not relicensed by this repository's MIT license.
