# 한국어 규칙의 근거와 한계

확인일: 2026-09-16. 이 문서는 외부 연구를 바탕으로 작성한 요약과 설계 판단이다. 논문의 본문·그림·데이터·코드를 배포하는 문서가 아니다. 연구의 관찰과 이 스킬의 편집 효과를 구분한다.

## 근거 구분

- **관찰 연계:** 한국어 집단 비교에서 관련 특징을 관찰했다. 수정의 효과나 AI 판별력을 개별 문장에 보장하지 않는다.
- **편집 원칙:** 의미 보존, 가독성, 장르 적합성을 위한 휴리스틱이다.
- **검증 전 가설:** 특정 어휘·구조를 AI스럽다고 느끼는 한국어 독자 반응과 수정 효과는 별도 실험이 필요하다.

각 패턴은 여러 성격을 가질 수 있다. 25개 모두가 논문에서 검증된 규칙은 아니다.

## 1. 한국어 문체의 직접 관찰

Park 외의 KatFishNet은 인간 글 470개와 LLM 글 1,624개를 비교한다. 논설문·시·논문 초록을 다루며 인간 논설문은 초·중·고 학생 글이다. 쉼표 사용, 품사 결합 다양성, 띄어쓰기의 차이를 분석했고 부록에서는 체언·용언·어미 사용을 논의한다.[1]

연계할 패턴은 11번 명사화, 15번 문장 구조, 21번 반복, 22번 쉼표다. 이는 **설계상의 연결**이지 논문이 이 스킬의 예문이나 편집을 검증했다는 뜻은 아니다. 22번 중 대시·괄호 조언까지 한국어 실증 결과로 확대하지 않는다.

한계: 세 장르와 해당 모델·프롬프트 조건의 관찰이다. 인간·AI 혼합문, 업무 메일, 자기소개서로 일반화할 수 없다. 쉼표 앞뒤 품사 다양성과 전체 품사 다양성은 다른 지표이므로 “인간은 모든 다양성이 높다”고 요약하지 않는다. 띄어쓰기를 일부러 틀리거나 명사를 일괄 치환하지 않는다.

## 2. 일괄 단문화의 반대 근거

박종향·김은영의 대학 글쓰기 연구는 2021학년도 인간 글 20편과 2025학년도 AI 활용 글 49편을 비교했다. 해당 표본에서는 AI 활용 글의 평균 문장이 더 짧았고, 연결표현 다양성 차이는 유의하지 않았다. 서로 다른 학생 코호트이므로 AI 사용의 인과 효과로 단정할 수 없다. 본문의 MATTR 수치는 표와 불일치하는 부분도 있어 수치를 무비판적으로 재사용하지 않는다.[6]

설계 판단: 긴 문장·접속부사·명사를 금지하지 않는다. 독자가 논리를 따라갈 수 있는지 판단하고, 필요 없는 반복만 줄인다.

## 3. 생성 지침의 효과가 관찰된 범위

한국어 시 연구에서는 GPT-5.2 기본 생성·특징 지침 생성·인간 시의 40개 묶음을 평가자 5명이 블라인드로 비교했고, 지침 생성이 기본 생성보다 자연스러움 순위에서 높게 평가됐다. 다만 평가자 간 일치도가 낮았으며, 인간 시와 차이가 유의하지 않다는 결과는 동등성 입증이 아니다. KatFish 시 표본을 재사용하므로 독립 코퍼스의 재현으로 세지 않는다.[5]

설계 판단: 장르별 지침의 가능성을 보여 주지만 의미 보존형 산문 편집의 검증은 아니다. 시적 행갈이·띄어쓰기·리듬 규칙을 일반 문서에 이식하지 않는다.

## 4. 효과 평가

문체 전환 인간 평가 연구는 문체 변화·의미 보존·유창성을 구분하고, 평가자 정보·표본 추출·평가 절차·일치도 공개가 부족한 문제를 지적한다.[2]

이 프로젝트에서는 원문 / 일반 퇴고 요청 / v0.1 / v0.2의 비교를 권장한다. 같은 모델과 생성 설정을 쓰고 순서를 숨겨 한국어 독자가 평가한다. 자연스러움·말투·장르 적합성과 의미 보존을 별도로 평가한다. 조정용 자료와 평가용 자료를 분리한다. 이는 **평가 설계 제안이며 아직 시행한 벤치마크가 아니다.**

## 라이선스 경계

KatFish arXiv v5에는 CC BY-NC-ND 4.0이 표시되어 있다.[1] 공개 논문·코드·데이터 각각의 조건은 별도다. 이 프로젝트는 연구를 출처와 함께 요약할 뿐 제3자 자료를 MIT로 재라이선스하지 않는다. 데이터와 논문 그림·표, 코드 원문은 포함하지 않는다.
